# Midi2Building

This awesome and totally working project turns MIDI music into Minecraft block-building animations. It maps musical notes to blocks and places them in time with a song, using Minecraft's block sounds to make music while building.

## Usage

If you have a working copy of the application:

1. Click the note block in the main window to open a `.mid` or `.midi` file. Some example MIDI files are included in `src/main/resources/defaultSongs/`.
2. Click the crafting table to open the block-sound mapping window.
3. Browse octaves using the controls on the right. Each pitch shows how many times it occurs in the MIDI.
4. Click the sound slot beneath a pitch to choose a Minecraft block sound from the selection.

Flick the lever to activate the building!
